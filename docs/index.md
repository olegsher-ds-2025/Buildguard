# BuildGuard Documentation

BuildGuard is a SaaS platform for managing and supervising residential construction
projects, connecting homeowners, contractors and licensed inspectors around a single
project — with a computer-vision inspector and a project-grounded RAG assistant as its
core differentiators.

## Documents

- [High Level Design]({{ '/high-level-design' | relative_url }}) — domain decomposition,
  architecture, data model, AI layer, non-functional requirements, phased roadmap,
  risks and open decisions.

## Prototype

- [MVP demo]({{ '/demo/' | relative_url }}) — an interactive prototype of the phase 1
  scope (progress, phase timeline, budget with burn-rate alerting) plus the AI Vision
  Inspector review loop. Static page, mock data, no backend.
